02 · The Pipeline

From Raw File to Queryable Knowledge.

Every document passes through a multi-stage intelligence pipeline — extraction, understanding, embedding, and retrieval — before a single question is answered.

01
Document Ingestion
Upload via URL. DocIntel downloads and identifies the file format automatically. A Celery task is queued and tracked by job ID with SHA-256 caching — documents processed before are served instantly from the knowledge cache.
PDF DOCX XLSX PPTX PNG / JPG ZIP SHA-256 Cache Celery + Redis
02
Text Extraction + Vision OCR
Text is extracted from every page, sheet, and slide. Embedded images and scanned pages run through dual-engine OCR: Tesseract for structural layout + Gemini 2.0 Flash Vision for multilingual and complex scripts. Tables get sheet-aware flattening.
PyMuPDF pymupdf4llm Tesseract OCR Gemini Vision python-docx pandas / openpyxl python-pptx
03
Semantic Chunking
Extracted text is split into semantically coherent chunks using LangChain's header-aware recursive text splitters. Chunks preserve document structure — section boundaries, headers, and table context stay together.
LangChain Header-Aware Splitting Semantic Boundaries langchain-text-splitters
04
Embedding + Vector Indexing
Every chunk is embedded into a 1536-dimensional vector using OpenAI's text-embedding-3-small model. Embeddings are indexed in FAISS for sub-millisecond similarity search. Both the chunks and index are persisted to disk for zero-cost retrieval on repeat queries.
OpenAI text-embedding-3-small FAISS IndexFlatL2 1536-dimensional vectors Persisted to disk Parallel batching
05
RAG: Retrieval → Generation → Answer
When a question arrives: Gemini 2.0 Flash rewrites it into a broader step-back query. Both the original and rewritten queries independently search FAISS. The union of relevant chunks forms the grounded context. GPT-4o-mini generates a precise answer. Gemini 2.0 Flash then summarizes and refines it.
Gemini 2.0 Flash (step-back rewrite) Dual FAISS retrieval GPT-4o-mini (generation) Gemini 2.0 Flash (summarization) Context grounding

07 · Capabilities

Everything Enterprise Document Intelligence Requires.

📄
Multi-Format Parsing
PDF, DOCX, XLSX, PPTX, PNG, JPG, ZIP — every enterprise document format, extracted with structure preserved.
🔍
Dual-Engine OCR
Tesseract for structural layout + Gemini 2.0 Flash Vision for multilingual scripts — Tamil, Malayalam, Urdu, and more.
🧠
Step-Back Query Rewriting
Gemini reformulates every question into a broader semantic query. Both versions retrieve independently — union maximizes recall.
⚡
Async Ingestion Pipeline
Celery + Redis task queue. Upload and continue — processing happens in the background with real-time job status tracking.
💾
SHA-256 Document Cache
Previously processed documents are stored by hash. Zero redundant computation — the same document costs nothing on repeat ingestion.
🔒
Secure by Design
JWT authentication, bcrypt password hashing, MongoDB user storage, Redis-based rate limiting, and per-job ownership enforcement.
